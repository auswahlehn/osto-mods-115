## 64-bit port

Ported to the OSTO 64-bit client (115.02) for the OSTO toolbox mod list. Original author: Fruit (https://github.com/tera-private-mods/anti-bodyblock). The upstream repository has no license file. The mod only sends a fake S_PARTY_INFO to your own client; nothing is sent to the server. Chat command: bb (for example /8 bb to turn it on or off).
