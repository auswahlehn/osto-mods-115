# instant-everything
Skips the animation and progress bar when soulbinding and merging items.

Each mode can be toggled by using the in-game command `instant [mode]`, with `[mode]` being `enchant`, `upgrade`, `soulbind`, `merge`, or `dismantle`.

On the OSTO 115 client only `soulbind` and `merge` are active: enchanting and dismantling use OSTO's own windows and are left alone, so the `enchant`, `upgrade` and `dismantle` modes do nothing there.
